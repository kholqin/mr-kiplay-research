# Changelog

All notable changes to Mr.Kiplay Research are documented here.

## [0.1.0] - 2026-08-25

### Added

- Premium chiaroscuro dark-cyber workspace dashboard with gold light accents.
- Responsive desktop sidebar and mobile navigation.
- Reduced-motion-aware transitions and accessible interaction states.
- Authenticated workspace initialization and protected tRPC research procedures.
- Authorized project creation with target, scope, authorization reference, and compliance checklist.
- Findings register data model with severity, category, remediation, and lifecycle status.
- Workflow module tracking for Android, web, binary, network, fuzzing, source analysis, correlation, evidence, and reporting.
- Evidence metadata model referencing object storage rather than storing file bytes in the database.
- Audit activity model and owner notifications for project creation and high-priority findings.
- Initial Vitest coverage for authentication and research safety validation.
- Professional README and MIT License.

### Security scope

This release contains no exploit execution, attack automation, arbitrary command runner, scanner launcher, or browser-triggered binary execution.
